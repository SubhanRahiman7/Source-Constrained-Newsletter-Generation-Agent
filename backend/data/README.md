# Dataset folder

Place your **assignment PDFs and articles** here. The pipeline only ingests files declared in `sources_manifest.json`.

## Layout

- `sources_manifest.json` — canonical list of sources with metadata (name, publication date, file path).
- `corpus/` — raw files (PDF, `.txt`, `.md`).
- `processed/` — generated by ingestion (do not edit): `chunks.jsonl`.

## Manifest fields

Each source entry must include:

- `id` — stable slug (used in chunk IDs).
- `source_name` — human-readable title for citations.
- `publication_date` — ISO date `YYYY-MM-DD` when known; use `unknown` if truly unavailable (cite as `unknown` in output).
- `file` — path relative to `backend/data/` (e.g. `corpus/report.pdf`).
- `type` — `pdf` | `text` | `markdown`.

## Chunk metadata (written to `processed/chunks.jsonl`)

Every line is JSON with:

- `chunk_id`
- `text`
- `source_name`
- `publication_date`
- `retrieval_date` (run date of ingestion)
- `location` (page number for PDFs, or section/chunk label for text)

After adding or changing sources, run:

```bash
cd backend
python scripts/ingest.py
```
